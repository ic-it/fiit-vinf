====== Third consultation - Spark extraction and Wikipedia join ======

[[user:icit:start|Project]] · [[user:icit:odovzdanie1|First submission]] · [[https://vi2026.ui.sav.sk/doku.php?id=projekty.pre.rok.2026#konzultacia3spracovanievelkychdat|Requirements]]

Updated on 10 November 2026 for the third consultation. This stage moves extraction and linking to Apache Spark. The existing crawler, sequential parser and search index remain independent. No new FishBase HTTP collection was needed.

===== What changed =====

The new vinf-spark workspace library reuses FishBaseProfile and the shared Pydantic contracts. Spark mapPartitions executes the same REGEX extraction on all 15,543 saved HTML pages. A DataFrame window chooses one record per FishBase ID using newest retrieval time and then UUID, matching the first indexer's policy. Separate commands process Wikipedia XML and join the results.

Measured with PySpark 3.5.9, Java 17 and master local[2]. This is a real Spark run on one laptop with two concurrent task slots and 4 output/shuffle partitions, not a multi-machine performance test. For a remote master, install the same workspace dependencies on executors and mount the raw packet paths identically. The input catalog is partitioned; raw pages are read by workers rather than collected on the driver.

<code text>
saved FishBase catalog + raw HTML.gz -> Spark workers / existing REGEX profile
                                    -> outcomes + deduplicated species JSON.gz

official Wikipedia XML.bz2          -> Spark file partitions / streaming REGEX workers
                                    -> main-namespace pages JSON.gz

FishBase species + Wikipedia pages  -> Spark scientific-name join
                                    -> records / review / unmatched JSON.gz
</code>

===== Wikipedia input and extraction =====

The complete title/offset index of the official 20261101 English Wikipedia multistream dump was scanned for all 9,724 FishBase scientific names and available common names. It found 5,507 scientific-title matches and 2,420 common-title matches. These select candidate input, not automatic entity links. Redirects found for corpus titles guide retrieval of their target articles in a subsequent pass.

The resulting selection contains 4,492 non-overlapping byte ranges made of complete bzip2 members. Exact HTTP Content-Range and length are verified; a server returning the whole file is rejected. Downloaded bytes are original dump bytes, with URL, offsets, retrieval time and SHA-256 retained. Neighbouring pages within selected members are processed too. Existing verified ranges are reused on repeated fetches. This is an automatically selected corpus from across the whole dump, not two arbitrary dump parts or manually chosen API pages.

| Selected original XML ranges | 604,635,453 | [[https://dumps.wikimedia.org/enwiki/20261101/enwiki-20261101-pages-articles-multistream.xml.bz2|Dated parent dump]]; per-range SHA-256 and offsets in metadata |

The selected ranges contain 552,300 XML page records and 416,705 main-namespace pages. Original XML: 2,579,823,499 bytes; bzip2: 604,635,453 bytes. The index is reported separately and is not counted as XML content. These are file sizes, not network traffic. The full 27 GB parent XML file was not downloaded.

Spark partitions the input file paths. Each worker reads concatenated bzip2 members directly, with a 256 KiB input chunk and a buffer bounded by one XML page plus that chunk. REGEX frames pages and extracts page ID, namespace, title, revision, timestamp and text; html.unescape decodes XML entities. Further expressions select a Speciesbox/Taxobox, explicit taxon or genus/species fields, optional family/order/authority/status, categories and a lead paragraph. No XML/HTML DOM parser, XPath or MediaWiki API is used. Raw XML remains compressed and unchanged. One file is handled by one task, so input parallelism is bounded by the number of dump files; it does not split a single bzip2 file between workers.

===== Join rule and useful attributes =====

The join key is the scientific name normalized with Unicode NFKC, casefold and collapsed whitespace, shared with FishBase. Common names help retrieve candidates but do not establish a link: several species can share one, and Wikipedia titles may use common names. For example, Glauert's anglerfish contains the scientific name Allenichthys glauerti.

Only main-namespace, non-redirect, non-disambiguation pages with an extracted scientific name participate. An exact key with more than one Wikipedia candidate is marked ambiguous. Conflicting explicit families are kept for review. An absent family is marked not_available, not reported as confirmed agreement. Accepted links preserve both sources; one source's conservation status does not overwrite the other.

Useful Wikipedia additions are the lead description, categories, explicit taxonomy/authority and conservation status with its status system. Page ID, revision ID, URL, timestamp, input file and wikitext SHA-256 provide provenance. These fields are available for the next search-index stage; the first submission's index has not been silently replaced.

===== Verification =====

The independent scripts/validate_spark.py audit compared all 9,724 Spark species records and source metadata with the original sequential parser's deduplicated results. They are equal. It also sequentially framed the original bzip2 XML without Hadoop and checked the complete set of 416,705 main-namespace page IDs against Spark output. Accepted links have matching scientific keys and no accepted redirects, disambiguations or family conflicts. Linked and unmatched identities form a complete, disjoint partition of the FishBase species set. The audit completed with no errors.

Two small extraction test methods use seven unchanged official XML pages. They check scientific names, conservation fields, lead descriptions, revision provenance, inline parameters, nested references, disambiguated genus names and preservation of subspecies rank. They also cover empty parameters, redirects, excluded namespaces and streaming across concatenated bzip2 members. One HTTP-range test checks exact ranges, verified reuse and rejection of full-file responses. The existing FishBase extraction tests remain in place.

Source raw packets, the old parsed snapshot and the old search index are retained independently.

===== Actual REGEX code =====

The following is the executable Wikipedia extractor, not pseudocode:

<code python>
"""REGEX extraction from MediaWiki XML records and unrendered wikitext.

Extraction uses REGEX without an XML/HTML parser, XPath or MediaWiki API. This is a
deliberately limited extractor for the common taxobox/speciesbox conventions.
"""

import bz2
import gzip
import hashlib
import html
import re
from pathlib import Path
from urllib.parse import quote

from vinf_core.records import species_key

from vinf_spark.models import WikiPage

VERSION = "mediawiki-taxobox-regex/1"
PAGE = re.compile(r"<page>\s*(.*?)$", re.DOTALL)
TEXT = re.compile(r"<text\b[^>]*>(.*?)</text>|<text\b[^>]*/>", re.DOTALL)
TAXOBOX = re.compile(
    r"\{\{\s*(?:speciesbox|subspeciesbox|taxobox|automatic[ _]taxobox)\s*\n(.*?)(?:\n\}\}|\Z)",
    re.IGNORECASE | re.DOTALL,
)
PARAMETER = re.compile(
    r"\|[ \t]*([a-z_0-9 ]+)[ \t]*=[ \t]*(.*?)(?=\|[ \t]*[a-z_0-9 ]+[ \t]*=|\n|$)",
    re.MULTILINE | re.IGNORECASE,
)
NESTED_TEMPLATE = re.compile(
    r"\{\{(?!\s*(?:speciesbox|subspeciesbox|taxobox|automatic[ _]taxobox)\b)[^{}]*\}\}",
    re.IGNORECASE,
)
LATIN = re.compile(r"[A-Z][a-zA-Z-]+ [a-z][a-z-]+(?: [a-z][a-z-]+)?")
PAGE_END = re.compile(r"</page\s*>")


def page_fragments(path: Path):
    """Stream concatenated bzip2 members without Hadoop split-boundary overlap.

    The buffer is bounded by one XML page plus a 256 KiB input chunk. Dump
    files are Spark work items; neither a whole file nor its XML tree is loaded.
    """
    opener = (
        bz2.open
        if path.suffix == ".bz2"
        else gzip.open
        if path.suffix == ".gz"
        else open
    )
    with opener(path, "rt", encoding="utf-8") as stream:
        buffer = ""
        for chunk in iter(lambda: stream.read(256 * 1024), ""):
            buffer += chunk
            while match := PAGE_END.search(buffer):
                fragment, buffer = buffer[: match.start()], buffer[match.end() :]
                if "<page>" in fragment:
                    yield fragment
        if "<page>" in buffer:
            raise ValueError(f"Incomplete XML page in {path}")


def clean(value: str) -> str:
    value = re.sub(r"<!--.*?-->", " ", value, flags=re.DOTALL)
    value = re.sub(
        r"<ref\b[^>]*>.*?</ref\s*>|<ref\b[^>]*/>",
        " ",
        value,
        flags=re.IGNORECASE | re.DOTALL,
    )
    value = re.sub(r"\[\[(?:[^\]\n|]+\|)?([^\]\n]+)\]\]", r"\1", value)
    value = re.sub(r"\{\{[^{}]*\}\}", " ", value)
    value = re.sub(r"<[^>]*>", " ", value)
    return " ".join(html.unescape(value).replace("'''", "").replace("''", "").split())


def lead_text(wikitext: str) -> str:
    # A lead paragraph usually starts with the bold article name after infoboxes.
    match = re.search(
        r"^(?![|{}!=#*])(?=[^\n]*''')[^\n]+(?:\n(?!\s*\n|==)[^\n]+)*",
        wikitext,
        re.MULTILINE,
    )
    return clean(match[0])[:4000] if match else ""


def extract_page(fragment: str, dump_file: str) -> WikiPage | None:
    page = PAGE.search(fragment)
    if not page:
        return None  # trailing </mediawiki>, not an article
    xml = page[1]
    namespace = re.search(r"<ns>(\d+)</ns>", xml)
    if not namespace or namespace[1] != "0":
        return None
    title = re.search(r"<title>(.*?)</title>", xml, re.DOTALL)
    page_id = re.search(r"<id>(\d+)</id>", xml)
    text = TEXT.search(xml)
    if not title or not page_id or text is None:
        raise ValueError("Main-namespace page is missing title, ID or text.")
    title = html.unescape(title[1])
    wikitext = html.unescape(text[1] or "")
    redirect = re.search(r'<redirect\b[^>]*title="([^"]*)"', xml)
    revision = re.search(r"<revision>\s*<id>(\d+)</id>", xml)
    timestamp = re.search(r"<timestamp>(.*?)</timestamp>", xml)
    box_view = re.sub(
        r"<ref\b[^>]*>.*?</ref\s*>|<ref\b[^>]*/>",
        " ",
        wikitext,
        flags=re.IGNORECASE | re.DOTALL,
    )
    for _ in range(16):
        box_view, removed = NESTED_TEMPLATE.subn(" ", box_view)
        if not removed:
            break
    box = TAXOBOX.search(box_view)
    fields = (
        {
            key.strip().lower().replace(" ", "_"): clean(value) or None
            for key, value in PARAMETER.findall(box[1])
        }
        if box
        else {}
    )
    name = fields.get("taxon") or fields.get("binomial")
    genus, species = fields.get("genus"), fields.get("species")
    if genus:
        genus = re.sub(r"^([A-Z][a-zA-Z-]+)\s*\([^)]*\)$", r"\1", genus)
    if not name and genus and species:
        name = f"{genus} {species}"
        if fields.get("subspecies"):
            name += f" {fields['subspecies']}"
    name = name if name and LATIN.fullmatch(name) else None
    return WikiPage(
        page_id=int(page_id[1]),
        title=title,
        revision_id=int(revision[1]) if revision else None,
        timestamp=timestamp[1] if timestamp else None,
        url="https://en.wikipedia.org/wiki/"
        + quote(title.replace(" ", "_"), safe="()_"),
        dump_file=dump_file,
        wikitext_sha256=hashlib.sha256(wikitext.encode()).hexdigest(),
        redirect=html.unescape(redirect[1]) if redirect else None,
        scientific_name=name,
        species_key=species_key(name) if name else None,
        genus=genus or (name.split()[0] if name else None),
        family=fields.get("familia") or fields.get("family"),
        order=fields.get("ordo") or fields.get("order"),
        authority=fields.get("binomial_authority") or fields.get("authority"),
        status=fields.get("status"),
        status_system=fields.get("status_system"),
        description=lead_text(wikitext),
        categories=tuple(
            sorted(set(re.findall(r"\[\[Category:([^\]|]+)", wikitext, re.IGNORECASE)))
        ),
        disambiguation=bool(
            re.search(
                r"\{\{\s*(?:disambiguation|disambig|dab)\b", wikitext, re.IGNORECASE
            )
        ),
    )
</code>

FishBase worker extraction reuses the original profile:

<code python>
def _fishbase_partition(lines, crawled: str):
    profile = FishBaseProfile()
    for line in lines:
        metadata = DocumentMetadata.model_validate_json(line)
        source = source_document(metadata)
        body = read_body(Path(crawled), source)
        selection = profile.select(body)
        record = error = None
        status = ParseStatus.REJECTED
        if selection.selected:
            try:
                record = profile.extract(body, source)
                status = ParseStatus.ACCEPTED
            except ValueError as exc:
                error, status = str(exc), ParseStatus.ERROR
        yield ParsedPage(
            source=source,
            fingerprint=fingerprint(profile.version, source.model_dump_json()),
            status=status,
            reason=selection.reason,
            record=record,
            error=error,
        ).model_dump_json()
</code>
