====== First submission - FishBase species search ======

[[user:icit:start|Project]] · [[user:icit:konzultacia2|Crawler]] · [[user:icit:implementation|Code and full examples]]

Snapshot: 2026-10-25–2026-10-27 (UTC). I collected 15,543 HTML pages and indexed 9,724 source records. Collection was stopped deliberately; 837,737 pending URLs and 50 deferred tasks remain saved. This is a partial corpus, not a complete FishBase mirror.

===== Goal, source and five extraction examples =====

Search English fish descriptions from [[https://www.fishbase.se/|FishBase]] using words, phrases and Boolean expressions. A generic crawler collects linked HTML; a separate REGEX extractor selects species summaries and extracts names, taxonomy, environment, distribution, reported maximum length, biology and available IUCN status. Missing facts stay null.

===== Search scenarios and observed answers =====

Each scenario states a search intention and its literal text conditions. Words can occur in different sections of a description; quoted phrases must match inside one section. The returned text provides the context for interpreting habitats, diet and conservation status. Counts refer to this snapshot, and the displayed species are examples of matching descriptions.

==== Query 1 ====

**Which marine fish descriptions refer to the tropical or subtropical Western Pacific?**

<code>
marine "Western Pacific" (tropical OR subtropical) -freshwater
</code>

Explore a region and climate together. The text must contain marine, the exact phrase Western Pacific, and tropical or subtropical. The standalone word freshwater excludes the document, including descriptions of species that also occur in fresh water.

Observed answer: 528 matching descriptions. First three with TF-IDF cosine: Odontanthias unimaculatus; Odontanthias rhodopeplus; Taenioides eruptionis.

==== Query 2 ====

**Which freshwater fish descriptions mention threatened species in the Mekong or Chao Phraya basins?**

<code>
freshwater (Mekong OR "Chao Phraya") (Endangered OR Vulnerable)
</code>

Find regional conservation candidates. The text must contain freshwater, either Mekong or the exact phrase Chao Phraya, and Endangered or Vulnerable. Endangered also matches the word in Critically Endangered. A mention of either river is sufficient; the query does not require both.

Observed answer: 17 matching descriptions. First three with TF-IDF cosine: Oxygaster pointoni; Ambastaia sidthimunki; Oreoglanis siamensis.

==== Query 3 ====

**Which marine descriptions combine reef habitats with crustacean or mollusk feeding terms?**

<code>
marine ("coral reefs" OR "rocky reefs") (crustaceans OR mollusks OR molluscs)
</code>

Explore habitat and diet vocabulary together. The text must contain marine, either exact phrase coral reefs or rocky reefs, and at least one of crustaceans, mollusks or molluscs. Both spellings of mollusks are explicit alternatives. Read the returned description to check the feeding relationship.

Observed answer: 54 matching descriptions. First three with TF-IDF cosine: Choerodon robustus; Polyamblyodon gibbosum; Symphorichthys spilurus.

==== Query 4 ====

**Which freshwater fish descriptions connect cave habitats with blindness?**

<code>
freshwater (cave OR caves OR subterranean) (blind OR eyeless)
</code>

Find candidates for studying cave-related loss of vision. The text must contain freshwater, at least one of cave, caves or subterranean, and blind or eyeless. Singular and plural forms are written explicitly because the search does not perform stemming.

Observed answer: 14 matching descriptions. First three with TF-IDF cosine: Oxyeleotris caeca; Ophisternon candidum; Sinocyclocheilus aquihornes.

==== Query 5 ====

**Which freshwater fish descriptions mention migration in Europe or the Danube without marine references?**

<code>
freshwater (migratory OR potamodromous) (Europe OR Danube) -marine
</code>

Explore freshwater migration with European distribution terms. The text must contain freshwater, migratory or potamodromous, and Europe or Danube. The standalone word marine excludes the document. Danube is an alternative to Europe, so a description need not contain the broader region's name.

Observed answer: 33 matching descriptions. First three with TF-IDF cosine: Leuciscus leuciscus; Leuciscus aspius; Barbus barbus.

===== Libraries and architecture =====

Python 3.12 and uv manage four independent stage libraries and vinf-core. Core owns Pydantic file contracts; crawl, parse, index and search have separate CLI commands and separate data directories. Requests handles HTTP, Protego evaluates robots, Typer/Rich provide the CLI, and standard gzip/lzma handle optional compression. tiktoken is used only for measurements. Extraction, index construction and ranking are self-written; no database or search framework is used.

===== HTTP policy and actual metadata =====

Final settings: robots=respect; minimum interval 10s per origin; site pacing; 1 worker; no proxies. Longer robots timing and server cooldowns take precedence. Connect/read timeouts are 10/30s, responses are limited to 10 MiB and redirects to five. These bound waits and response size. Redirects are checked again; TLS verification stays enabled.
User-Agent: ''FIITVinfCrawler/0.10 (educational project; +https://vi2026.ui.sav.sk/doku.php)''. Accept requests HTML/XHTML. Failures remain available for retry.

===== Implemented REGEX code =====

The [[user:icit:implementation|implementation appendix]] includes the actual URL extraction source (tag/attribute regexes, relative-link resolution and scope checks) and entity extraction source (summary selection, fields and numeric normalization). ===== TF index and three ranking methods =====

The indexer selects the newest record per (source, FishBase ID), assigns dense docIDs and externally sorts term occurrences with bounded buffers. Postings store TF, word positions, UTF-8 offsets and section identity. DF is computed during construction. An on-disk sorted lexicon addresses blocks in postings.bin. Search text is stored once; queries merge posting streams and keep a top-k heap.
One shared index contains 9,724 documents, 56,649 terms and 3,135,598 word occurrences, after removing 5,536 duplicate source records. Stop words are disabled in this snapshot. A changed parsed catalog triggers a rebuild; unchanged input is verified and reused. Search never builds an index.

^ Method ^ IDF and scoring ^
| TF-IDF sum | %%idf=ln(N/DF); sum(TF×idf)%% over distinct positive query terms; no length normalization |
| TF-IDF cosine | %%idf=ln((N+1)/(DF+1))+1; weight=(1+ln(TF))×idf%%; normalized query-document dot product |
| BM25 (additional experiment) | %%idf=ln(1+(N−DF+0.5)/(DF+0.5))%%; TF saturation and length normalization; k1=1.2, b=0.75 |

The required comparison uses the two TF-IDF variants with non-probabilistic IDF. BM25 is an additional experiment.
Quoted phrases require consecutive words in one section and matching punctuation in the stored span. Case, NFKC and whitespace are normalized. reef-associated is a different token from reef. [[user:icit:implementation|Query semantics and optional stop words]].

Linear TF rewards repeated query words without a document-length penalty. Cosine normalizes the complete weighted vector; BM25 saturates TF and adjusts for document length. The changed leaders show that these choices affect ordering even though Boolean candidate sets are identical.

HTML is 4.67× smaller in gzip. Its original size exceeds 500 MB; queue overhead is reported separately. Requests decodes HTTP content encodings before storage, so these are HTML-body sizes, not wire-traffic measurements. They include page markup and URL variants; deduplication counts are shown separately. Accepted pages are selected automatically by REGEX, not manually judged for relevance. Other pages remain in raw storage and are excluded from the species index. The full website is not claimed as downloaded.
Token bonus: tiktoken 0.14.0, cl100k_base. Counts cover complete raw HTML including markup and, separately, deduplicated indexed texts. Each document is counted in memory without decompressed files. BPE counts differ from the index's word-token count.
REGEX-test bonus: tests/test_extraction_gold.py checks 20 independently labeled real species pages and two real negative pages. Expected values were transcribed from source HTML. Fixtures preserve original bytes and SHA-256; cases include slug IDs, several environments and IUCN states, absent lengths, thousands separators, parenthesized sex labels and TL/SL/WD/NG measurements.
The extractor depends on FishBase's HTML template. Section text can retain reference and navigation labels; the gold cases check the listed fields rather than corpus-wide accuracy.
